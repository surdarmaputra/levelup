## What Good RFC Writing Looks Like

- Short sentences for facts. Longer ones for nuance.
- Specific file paths, component names, hook names
- "We do X because Y" not "X is done in order to facilitate Y"
- Technical precision over elegance
- Direct statements over hedging
- Numbers and specifics over vague qualifiers
