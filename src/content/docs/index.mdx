## Catalog

Every material is a sequenced roadmap, not a reference dump. Each step states why it comes
where it does, what you should be able to explain afterwards, and how to verify you actually
got it.

## How these materials are built

Each material follows the same shape, so what you learn about *how to work through one*
transfers to the next.

- **One real domain per material.** The hard problems are load-bearing, not bolted on as demos.
- **Sequenced, not alphabetised.** Every step exists because the previous one created the pain it solves.
- **`LEARN` and `BUILD` steps.** Some things only survive being struggled with. Those steps tell your AI agent to stay a tutor and refuse to write the code.
- **Verifiable.** Acceptance criteria and anti-pattern lists per step, so "done" is checkable rather than felt.
- **Agent-ready.** Each material ships the harness files — `AGENTS.md`, a reviewer prompt, rubrics — so a coding agent is useful rather than merely plausible.
